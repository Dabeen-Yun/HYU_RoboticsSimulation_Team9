## 슬라이드 3. 01 Problem Formulation & Research Hypothesis

> 이 슬라이드의 목표는 하나입니다. 청중이 **"Ant가 못 걷는 이유는 지형 모양이 아니라, 지금 밟고 있는 바닥이 어떤 바닥인지 모르기 때문"**이라는 문제 의식을 갖게 하는 것입니다. 뒤의 모든 결과가 이 문제로 돌아옵니다.

### 연구 배경
**[슬라이드 문구]**
- 강화학습 보행 정책은 학습한 시뮬레이션 환경에 과적합되기 쉽다.
- 실제 배포 환경에서는 지형 모양, 마찰, 질량, 접촉 특성이 학습 때와 다르다.
- 과제 목표: 처음 보는 환경에서도 잘 걷는 Ant 정책 만들기. 단, **보상 함수와 로봇 하드웨어는 원본 그대로** 둔다.

### Baseline의 한계
**[슬라이드 문구]**
- Baseline(원본 Isaac-Ant-v0)은 **평면 바닥 하나, 마찰 1.0, 고정 질량**에서만 학습되었다.
- **바닥 충돌체만 바꿔도 성능이 무너진다.** 같은 평지를 삼각형 메쉬로 바꾸면 129.6 → 41.7 (**−68%**)
- 처음 보는 지형과 물성에서는 129.6 → 36.3 (**−72%**)
- 반면 **평면 바닥 위에서 마찰만 바꾸면** 거의 영향이 없다 (마찰 0.3 / 0.5 / 0.7 / 1.0 → 120 / 126 / 131 / 130).
  - 즉 문제는 마찰 값 자체가 아니라 **"바닥과 어떻게 접촉하는가"(접촉 동역학)**를 정책이 구분하지 못하는 데 있다.

**[근거]**
- 129.6: `results/official/baseline_flat.txt`
- 41.7: `results/eval/baseline_flatmesh.npz` (task `Isaac-Ant-Blind-Flat-v0`, 높이 0인 평평한 메쉬)
- 36.3: `results/official/baseline_test.txt`
- 마찰 변화: `results/diag/baseline_Isaac-Ant-v0_f*.npz`

**[그림]** `fig1_motivation_baseline_collapse.png` (막대 3개: 기존 / 평평한 메쉬 / 처음 보는 환경)

### 문제 정의
**[슬라이드 문구]**
- **연구 질문:** 처음 보는 환경에서 Ant의 보행 성능은 왜 떨어지는가?
- **P1. 학습 분포 과적합:** 단 하나의 바닥에서만 학습했기 때문에, 그 바닥에 맞는 질주 보법 하나만 알고 있다.
- **P2. 바닥 물성의 관측 불가능성:** Baseline 관측(60차원)은 현재 프레임의 몸통 상태, 관절 상태, 발 관절 반력뿐이다.
  - 이것만으로는 지금 밟는 바닥이 미끄러운지, 딱딱한 평면인지, 울퉁불퉁한 메쉬인지 **구분할 수 없다.**
  - 관절 반력은 바닥 접촉력을 직접 측정한 값이 아니고, 이력도 없어서 미끄러짐 같은 시간적 변화를 볼 수 없다.
  - 결과적으로 바닥이 바뀌어도 **보법을 바꿀 근거가 없다.**
- **P3. 지형 맹목성:** 앞에 무엇이 있는지 보는 센서가 없다. 높이 관측(`base_height`)도 월드 기준이라 솟은 지형 위에서는 의미가 틀어진다.

**[근거]**
- Baseline 관측 구성: `ant_env_cfg.py`의 `ObservationsCfg`
  - 몸통 높이 1, 선속도 3, 각속도 3, yaw/roll 2, 목표 각도 1, up/heading 투영 2, 관절 위치 8, 관절 속도 8, 발 관절 반력 24(`body_incoming_wrench`), 이전 행동 8 → 합계 60
- 학습 조건: 같은 파일의 `static_friction=1.0`. 랜덤화 이벤트는 reset만 있다.

### 연구 가설
**[슬라이드 문구]**
- **H1 (원인 가설):** 성능 저하의 핵심 원인은 정책이 바닥 물성을 모른다는 것이다.
  - 바닥 정보(마찰, 질량, 바닥 종류)가 주어지면 **한 정책이** 평면에서는 빠르게, 험지에서는 안정적으로 걸을 수 있다. 평지 성능과 험지 성능 사이의 trade-off가 사라진다.
- **H2 (추정 가설):** 바닥 물성은 직접 측정할 수 없지만, **발의 접촉력과 최근 운동 이력**에 드러난다.
  - 따라서 정답 물성을 아는 **교사**의 행동을, 접촉 센서와 이력만 가진 **학생**이 모방해 재현할 수 있다.
- **H3 (일반화 가설):** 학생은 정해진 라벨이 아니라 **실제 접촉 반응**을 보고 판단한다.
  - 따라서 학습 때 보지 못한 지형과 물성에서도 Baseline보다 잘 걷는다.

> 발표 멘트 예시: "사람은 빙판에 발을 디디는 순간 미끄러움을 느끼고 걸음을 바꿉니다. Baseline Ant에게는 그 '발바닥 감각'이 없습니다. 저희는 이 감각을 주면 일반화 문제가 풀린다고 가정했습니다."

## 슬라이드 4. 02 Experimental Design: 학습 및 검증 환경

> 템플릿에 이미 넣은 지형 그림(`fig1_terrains`, `fig1_train_tiles`, `fig1_test_tiles`)을 그대로 두고, 아래 비교표를 옆이나 아래에 추가합니다.

  - **처음 보는 환경:** 일반화되었는가?

## 슬라이드 5. 02 Experimental Design: 추가 센서 및 고려 요소 / 가설 검증을 위한 설계

### 추가 센서 및 고려 요소
**[그림]** `fig0_method_teacher_student.png` (교사-학생 구조도). 이 슬라이드의 메인 그림입니다.

**[슬라이드 문구: 센서 표]** 각 센서가 어떤 문제(P)를 해결하는지 같이 적습니다.

| 추가 요소 | 내용 | 해결 대상 |
|---|---|---|
| **발 접촉 센서** (ContactSensor ×4) | 발마다 수직력, 접선력, **마찰 사용량**(접선/수직), **미끄러짐 속도** → 16차원 | P2: 바닥 물성 관측 |
| **최근 8스텝 이력** (0.13초) | 관절 속도, 행동, 몸통 선·각속도, 발 접촉 → 304차원 | P2: 시간에 따른 접촉 반응으로 바닥 추정 |
| 높이맵 (RayCaster) | 몸 앞 1.5 m, 뒤 0.5 m, 좌우 ±0.6 m, 10 cm 간격 → 273차원 | P3: 지형 모양 인식 (보조) |
| **정답 물성** (교사에게만) | 유효 마찰, 질량 비율, 평면 바닥 여부 → 3차원 | H1 검증용. 시뮬레이터에서만 얻을 수 있어 배포 불가 |

- USD 파일은 센서 추가 외에는 변경하지 않았다. 보상 함수와 하드웨어(링크, 관절)는 원본 그대로다.

**[슬라이드 문구: 학습 절차]**
1. **교사 학습 (PPO, 2000 iter):** 학생 관측 + 정답 물성 3개 → 원본 보상으로 학습한다. 원본 정책 가중치에서 이어서 학습한다.
2. **학생 학습 (DAgger 증류, 1500 iter):** 정답 물성 없이 653차원 관측만으로 교사의 행동을 모방한다. 손실은 ‖π_학생(o) − π_교사(o, e)‖².
3. **배포:** 학생 정책 하나만 사용한다. 지형마다 정책을 바꾸는 전환 장치는 없다.

### 가설 검증을 위한 설계
**[슬라이드 문구: 실험 설계 표]**

| 가설 | 비교 | 확인할 것 |
|---|---|---|
| H1 | 교사 vs Baseline (기존 / 처음 보는 환경) | 바닥 정보가 있으면 두 환경 모두에서 Baseline보다 높은가 |
| H2 | 학생 vs 교사 | 정답 없이 접촉과 이력만으로 교사 성능을 얼마나 회복하는가 |
| H3 | 학생 vs Baseline (처음 보는 환경, 지형별, 마찰 0.1~2.0) | 학습 밖 지형과 물성에서도 이기는가 |
| 상한 | **오라클** (처음 보는 환경에서 직접 학습, 제출용 아님) | 이 시뮬레이터에서 도달 가능한 최대치 |

**[슬라이드 문구: 공정한 비교를 위한 고려 요소]**
- **개체별 단일 마찰:** 원래 방식은 부품마다 마찰을 따로 뽑아서, 개체 평균이 거의 같아진다. 그러면 바닥 물성을 추정할 대상 자체가 사라지므로, 개체마다 하나의 값을 쓰도록 바꿨다.
- **종료 조건 허점 차단:** 원래 종료 조건(월드 z < 0.31)은 솟은 지형 위에서 웅크려 걷는 보법을 허용한다. 그래서 **학습 때만** 지형 기준 높이로 종료한다. 평가는 원래 조건 그대로다.
- **오라클 상한 측정:** 처음 보는 환경에서 직접 학습한 정책도 67.2에 그친다. 메쉬 접촉 자체의 한계를 분리해서 볼 수 있다.
- **재현성:** 교사-학생 전체 과정을 학습 seed 2개로 반복했다.

## 슬라이드 6. 03 Performance Evaluation & Analysis

### 주요 성능 결과
**[그림]** `fig2_main_result.png` (메인)

**[슬라이드 문구: 대표 수치]**

| | 기존 환경 | 처음 보는 환경 |
|---|---|---|
| Baseline | 129.57 ± 29.68 | 36.28 ± 18.29 |
| **Ours (학생)** | **138.35 ± 36.05** | **64.64 ± 27.65** |
| 교사† (참고, 배포 불가) | 145.48 ± 27.84 | 56.75 ± 28.21 |
| 오라클 상한 (참고) | – | 67.2 |

- 처음 보는 환경 **+28.4점 (+78%, p = 8×10⁻¹⁵)**, 오라클 상한의 **96%**
- 기존 환경 +8.8점 (p = 0.06): **원래 성능을 잃지 않음**

### Baseline 비교
**[슬라이드 문구]** 각 문장을 가설과 연결합니다.
- **R1 → H1 지지:** 교사는 기존 환경 145.5로 Baseline보다 **+15.9 (p = 0.0001)**, 처음 보는 환경에서도 +20.5다.
  - 바닥을 알면 평지에서 더 빨리 달리고(9.8 m/s, Baseline 8.6), 험지에서도 버틴다. **평지와 험지 사이의 trade-off가 사라진다.**
- **R2 → H2 지지:** 학생은 정답 물성 없이 기존 환경에서 교사의 **95%**(138.4)를 회복했다.
  - 발 접촉과 0.13초 이력만으로 "지금 밟는 바닥"을 구분한다.
- **R3 → H3 지지:** 처음 보는 환경에서 학생은 Baseline +78%이고, 오히려 **교사보다도 +7.9 높다 (p = 0.048).**

### 환경별 성능 차이
**[그림]** `fig3_per_terrain.png`, `fig4_friction_sweep.png`

**[슬라이드 문구: 지형별 표]** (처음 보는 환경, 개체 수 40 / 30 / 30)

| 지형 | Baseline | Ours | 차이 |
|---|---|---|---|
| 파도 (미학습) | 49.2 | **76.7** | +27.5 (p = 7×10⁻⁸) |
| 장애물 (미학습) | 38.5 | **68.8** | +30.3 (p = 4×10⁻⁸) |
| 거친 요철 (학습 범위의 1.7배) | 16.9 | **44.5** | +27.6 (p = 5×10⁻⁶) |

- **세 지형 모두** 큰 폭으로 개선됐다. 특정 지형에만 맞춘 향상이 아니다.

### 원인 분석
**[그림]** `fig5_survival_progress_unseen.png`, `fig6_reward_terms.png`

**[슬라이드 문구]**
- **점수 향상은 "더 멀리 가기"에서 나온다.**
  - 처음 보는 환경 전진 거리: 39 m → **68 m**
  - 평균 속도: 2.6 → **5.0 m/s**
  - 보상 항목 중 **progress 항**이 38.8 → 68.0으로 늘었다. 에너지와 관절 한계 같은 패널티는 거의 같다. **같은 비용으로 더 멀리 간다.**
- **학생이 교사보다 처음 보는 환경에 강한 이유 (H3의 근거)**
  - 처음 보는 환경은 접촉면마다 마찰이 섞여 있다. 그래서 교사가 받는 "정답 마찰"(평균값)이 실제 발밑 접촉과 어긋난다.
  - 학생은 실제 접촉 반응을 보고 판단하므로 이런 불일치에 강하다.
  - 장애물 지형에서 넘어진 비율은 교사 60%, 학생 30%다.
- **Baseline 성능이 무너진 원인 재확인 (P1, P2)**
  - 메쉬 바닥에서 Baseline은 평면에서처럼 질주하다가 미끄러지거나 걸린다.
  - Baseline에 처음 보는 환경 지형만 주고 물성을 기본값으로 둬도 31.4에 그친다. 즉 마찰이나 질량 값보다 **바닥 접촉 특성 차이**가 주원인이다.

## 슬라이드 7. 04 Future Directions

### 가설 검증 결과 정리
**[슬라이드 문구: 표]**

| 가설 | 결과 | 판정 |
|---|---|---|
| H1 바닥 정보가 trade-off를 없앤다 | 교사: 기존 145.5 (+15.9), 처음 보는 환경 56.7 (+20.5) | **지지** |
| H2 접촉과 이력으로 바닥을 추정할 수 있다 | 학생: 정답 없이 교사 평지 성능의 95% | **지지** |
| H3 처음 보는 환경으로 일반화된다 | +78%, 지형 3종과 마찰 9개 지점 모두 개선, 오라클의 96% | **지지** (거친 요철은 부분적) |

- 한 줄 결론: **"바닥을 느끼게 하자, 처음 보는 바닥에서도 걷는다."** 기존 성능을 유지하면서 처음 보는 환경 +78%를 달성했다.

### 현재 모델의 한계
**[슬라이드 문구]**
1. **넘어짐 증가:** 처음 보는 환경 생존율이 Baseline 81% → Ours 58%다.
   - 빠른 보법을 택하고 더 어려운 구간까지 도달하기 때문이지만, 안정성은 희생됐다.
2. **학습 범위 밖 거칠기:** 거친 요철에서는 교사(56.1)가 학생(44.5)보다 높고, 학생의 넘어짐(53%)이 이 지형에 집중된다.
   - 학생은 거칠기를 보고도 감속하지 않는다. 짧은 이력(0.13초)으로는 추정이 부족하다.
3. **메쉬 접촉 상한:** 처음 보는 환경에서 직접 학습한 오라클도 67.2에 그친다.
   - 시뮬레이터의 메쉬 접촉 특성 때문에 정책 개선만으로는 평면 수준(130)에 도달할 수 없다.
4. **고마찰 성능 저하:** 마찰이 높을수록 두 정책 모두 점수가 떨어진다(학생 0.4에서 65.3 → 2.0에서 38.5). 메쉬 위에서 발이 걸리는 현상이다.
5. **기존 환경 향상의 불확실성:** 기존 환경 +8.8은 p = 0.06이고, 두 번째 학습 seed에서는 130.8이다. **"유지"**로 보는 것이 정확하다.

### 추가 고려 요소
**[슬라이드 문구]**
- 더 넓은 물성 범위로 학습해 보았다(마찰 0.1~2.0). 저마찰은 개선됐지만, 기존 환경이 121.3으로 Baseline 아래로 떨어졌다. **범위를 넓히는 것만으로는 해결되지 않는다.**
- 몸통 IMU(기울기)를 추가해 보았지만 기존 관측과 정보가 겹쳐 이득이 없었다. 음성 결과다(seed 1개).
- 위 두 결과는 부차 실험이므로 한 줄씩만 언급한다. 근거: `results/README.md` 9절, 11절.

### 향후 개선 방향
**[슬라이드 문구]**
- **위험 인지 감속:** 추정한 바닥 상태가 위험하면 속도를 낮추는 보법. 생존율 개선이 목표다.
- **긴 이력 추정기:** 0.13초 이력 대신 GRU나 1D-CNN으로 수 초 단위 접촉 이력을 압축한다(RMA의 adaptation module 방식).
- **학습 지형 다양화:** 더 거친 요철을 학습에 넣되, 검증용 미학습 지형은 새로 구성해 공정성을 유지한다.
- **통계적 검증 강화:** 학습 seed를 3개 이상으로 늘린다.
- **물리 엔진 간 검증:** 다른 접촉 모델이나 실제 로봇으로의 전이(sim-to-real)를 확인한다.
