# 발표 구성안: 처음 보는 환경에서도 잘 걷는 Ant

> 5분 발표, 슬라이드 9장 내외. 비교 대상은 **Baseline**과 **Ours(교사-학생)** 두 가지로 한정한다.
> 그림: `results/figures/presentation/{en,ko}/` (PNG 300 dpi + PDF 벡터). 재생성: `python scripts/analysis/plot_presentation.py`
> 평가는 모두 `play_one_episode.py` 기준(`--seed 24 --num_envs 100`)이고, 점수는 **원본 Isaac-Ant-v0 보상**이다.

**한 줄 메시지:** *Ant가 낯선 바닥에서 무너지는 이유는 지형 모양뿐 아니라 "바닥이 어떤 바닥인지 모르기 때문"이다. 발의 접촉 감각과 최근 이력으로 바닥을 추정하게 하면(교사-학생), 처음 보는 환경 점수가 +78% 오르고 기존 환경 점수도 떨어지지 않는다.*

---

## 1. 인트로: 문제 정의와 가설 (약 1분, 슬라이드 2장)

### 슬라이드 1. 문제: Baseline은 바닥이 바뀌는 순간 무너진다
- 그림: `fig1_motivation_baseline_collapse`
- 같은 정책, 같은 보상, 같은 평지인데도 성능이 무너진다.
  - 기존 환경(해석적 평면 바닥): **129.6**
  - 평평한 삼각형 메쉬 바닥: **41.7 (−68%)**. 모양은 같고 **접촉 특성만** 다르다.
  - 처음 보는 지형과 물성: **36.3 (−72%)**
- **연구 질문:** 처음 보는 환경에서 Ant의 보행 성능은 왜 떨어지는가?
  - 관찰: 지형 *모양*보다 **바닥과의 접촉 동역학**(마찰, 충돌체, 질량)이 더 큰 원인이다.

### 슬라이드 2. 가설
- **H1 (원인):** 정책이 바닥 물성(마찰, 바닥 종류, 몸 질량)을 관측하지 못한다. 그래서 하나의 보법만 쓰게 되고, 평지 질주와 험지 보행 사이에 trade-off가 생긴다.
- **H2 (해결):** 바닥 물성은 직접 측정할 수 없지만 **발 접촉력과 최근 운동 이력**에 드러난다. 따라서 정답 물성을 아는 교사를 먼저 만들고, 학생이 접촉과 이력만으로 교사를 모방하게 하면, 배포 가능한 정책도 바닥에 맞는 보법을 고를 수 있다.
- **검증 기준:** (1) 처음 보는 환경 점수 향상, (2) 기존 환경 점수 유지(≥ Baseline), (3) 학습 범위 밖 물성에서의 강건성.

## 2. 실험 방법 (약 1분 30초, 슬라이드 2~3장)

### 슬라이드 3. 방법: 교사-학생 학습
- 그림: `fig0_method_teacher_student`
- **추가 센서 (USD 구조 변경 없음, 센서만 추가)**
  - 발 4개에 ContactSensor: 수직력, 접선력, 마찰 사용량(접선/수직), 미끄러짐 속도 → 16차원
  - 최근 8스텝(0.13초) 이력: 관절 속도, 행동, 몸통 속도, 발 접촉 → 304차원
  - 높이맵(RayCaster) 273차원은 지형 모양 인식용이다. 비교의 초점이 아니므로 한 줄로만 언급한다.
- **1단계, 교사 (PPO):** 학생 관측에 **정답 물성 3개**(유효 마찰, 질량 비율, 평면 바닥 여부)를 더해 학습한다. 시뮬레이터에서만 얻을 수 있으므로 배포할 수 없다.
- **2단계, 학생 (DAgger 증류):** 정답 물성 없이 653차원 관측만으로 교사의 행동을 모방한다(1500 iter). **배포되는 것은 학생 하나뿐이다.**
- **보상은 원본 그대로**이고, 하드웨어와 USD도 변경하지 않았다.

### 슬라이드 4. 학습 환경과 검증 환경 구성
- 그림: `results/figures/fig1_train_tiles.png`, `fig1_test_tiles.png` (기존 그림 재사용)
- **학습 환경**
  - 원래 평면 바닥 30%와 요철, 경사, 계단, 박스를 섞었다.
  - 도메인 랜덤화: 마찰 0.4~1.2(**개체마다 하나의 값**, 그래야 바닥 물성을 추정할 수 있다), 질량 ×0.8~1.2, 밀기
- **처음 보는 환경 (학습에 한 번도 사용하지 않음)**
  - 미학습 지형: 파도, 장애물
  - 학습 범위 밖 지형: 거친 요철(학습 범위의 1.7배)
  - 물성: 마찰 0.3~0.7, 질량 ×0.7~1.3 (학습 범위보다 넓음)
- **설계에서 고려한 점 (방법론적 엄밀성)**
  - 종료 조건 허점: 월드 z 기준 종료는 솟은 지형에서 웅크린 보법을 허용한다. 그래서 학습할 때만 지형 기준 종료를 쓰고, 평가는 원래 조건을 그대로 쓴다.
  - 상한 진단: 처음 보는 환경에서 직접 학습한 **오라클의 점수 67.2**를 성능 상한으로 제시한다.

## 3. 결과 (약 2분, 슬라이드 4~5장)

### 슬라이드 5. 주요 결과
- 그림: `fig2_main_result`

| | 기존 환경 | 처음 보는 환경 |
|---|---|---|
| Baseline | 129.6 ± 29.7 | 36.3 ± 18.3 |
| **Ours (학생)** | **138.4 ± 36.0** | **64.6 ± 27.7** |
| 교사† (참고, 배포 불가) | 145.5 ± 27.8 | 56.7 ± 28.2 |

- **처음 보는 환경:** +28.4점, **+78%** (p = 8×10⁻¹⁵). 오라클 상한(67.2)의 **96%**이다.
- **기존 환경:** +8.8점 (p = 0.06). 성능을 잃지 않았고, 오히려 소폭 높다.
- **H1 지지:** 교사가 기존 환경에서 145.5로 가장 높다. 바닥을 알면 평지에서 최고 속도로 달릴 수 있다는 뜻이고, trade-off가 사라진다.
- **H2 지지:** 학생은 정답 물성 없이 교사 평지 성능의 95%를 물려받았다. 처음 보는 환경에서는 오히려 **교사보다 높다**(+7.9, p = 0.048).
  - 해석: 처음 보는 환경은 접촉면마다 마찰이 섞여 있어서, 교사가 받는 "평균 마찰" 정답이 실제 접촉과 어긋난다. 학생은 실제 접촉 반응을 보고 판단한다.

### 슬라이드 6. 어디서 차이가 나는가: 지형별, 마찰별
- 그림: `fig3_per_terrain`, `fig4_friction_sweep`
- **지형별 (Ours − Baseline)**
  - 파도(미학습) +27.5
  - 장애물(미학습) +30.3
  - 거친 요철(학습 범위 밖) +27.6, 17 → 44
  - 세 지형 모두 p < 10⁻⁵이므로, **특정 지형에만 맞춘 향상이 아니다.**
- **마찰 스윕 (0.1~2.0):** Ours가 **9개 지점 모두에서** Baseline보다 높다. 학습 범위 밖(0.1, 1.5, 2.0)에서도 마찬가지다.
  - 성능 최고점은 마찰 0.4~0.6이고, 고마찰로 갈수록 두 정책 모두 떨어진다. 메쉬 위에서 발이 걸리는 문제다(한계 슬라이드에서 다룬다).

### 슬라이드 7. 행동 분석: 더 멀리 가지만, 더 자주 넘어진다
- 그림: `fig5_survival_progress_unseen`, `fig6_reward_terms`
- **전진 거리:** 39 m → **68 m**. 점수 향상의 대부분은 **progress 항**에서 나온다(38.8 → 68.0).
- **생존율:** Baseline 81%, Ours 58%. Ours가 더 멀리, 즉 더 어려운 구간(난이도가 거리에 따라 증가)까지 가기 때문이다.
  - 다만 넘어짐이 늘어난 것은 사실이므로 정직하게 보고한다.
- 에너지, 관절 한계 등 패널티 항은 거의 같다. **같은 비용으로 더 멀리 간다.**

### 슬라이드 8. 재현성
- 그림: `fig7_seed_repeats` (seed 2 학습이 끝나면 스크립트를 다시 실행해 자동 반영)
- 처음 보는 환경: seed 0 / 1에서 64.6 / 63.7. Baseline 대비 향상이 **안정적으로 재현**된다.
- 기존 환경: 138.4 / 130.8. 두 번 모두 Baseline 이상이지만 seed 간 편차가 있다.
  - 기존 환경에서의 향상은 "유지" 수준으로 표현하는 것이 정확하다.

## 4. 한계와 향후 과제 (약 30초, 슬라이드 1장)

### 슬라이드 9. 결론과 한계
- **결론:** 바닥 물성을 모르는 것이 일반화 실패의 핵심 원인이었다(H1). 접촉과 이력으로 이를 추정하는 교사-학생 구조로, **처음 보는 환경 +78%를 기존 환경 성능 손실 없이** 달성했다(H2).
- **한계**
  1. **메쉬 접촉 상한:** 오라클도 67.2에 그친다. 시뮬레이터의 메쉬 접촉 특성 때문에 처음 보는 환경에서 130에 도달하는 것은 정책 개선만으로는 불가능하다.
  2. **고마찰 성능 저하:** 학습 범위를 마찰 2.0까지 넓혀도 개선되지 않았다. 학습 부족이 아니라 메쉬 위 고마찰 접촉 자체의 어려움이다.
  3. **학습 범위 밖 거칠기:** 거친 요철에서는 교사(56)가 학생(44)보다 높다. 접촉 이력만으로는 큰 요철에 대한 추정이 부족하고, 이 지형에서 넘어짐이 집중된다.
  4. **넘어짐 증가:** 속도를 우선하는 보법이라서 생존율은 Baseline보다 낮다.
- **향후 과제**
  - 위험한 바닥을 인식하면 속도를 낮추는 적응형 보법
  - 순환 신경망 기반 장기 이력 추정기(RMA 방식 adaptation module)
  - 학습 seed를 3개 이상으로 늘린 검증
  - 실제 로봇이나 다른 물리 엔진으로의 전이 검증
