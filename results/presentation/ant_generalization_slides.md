## 슬라이드 3

Problem Formulation & Research Hypothesis

연구 배경: 보행 로봇의 가치는 '처음 보는 바닥'에서 결정된다

① 다리는 '길이 없는 곳'을 위해 존재한다
포장된 평지에서는 바퀴가 더 빠르고, 싸고, 효율적이다
다리 로봇이 필요한 곳: 계단·잔해·자갈·경사·진흙처럼 바퀴가 갈 수 없는 곳
예) 재난 현장 수색, 플랜트·터널 점검, 행성 탐사, 농업

② 실제 경로의 바닥은 미리 알 수 없고, 계속 바뀐다
점검 로봇의 하루 경로: 매끈한 에폭시 바닥 → 물기 있는 철판 → 격자 그레이팅 → 자갈 야적장
모든 바닥을 미리 학습시킬 수 없다
→ 하나의 정책이 현장에서 바로 적응해야 한다

③ 넘어지면 임무가 끝난다
넘어짐 = 임무 중단 + 장비 파손 + 사람의 직접 회수
예) NASA 화성 로버 Spirit: 2009년 부드러운 토양에 빠져 탈출하지 못했고, 결국 이동 임무를 종료했다
→ 지면 특성을 잘못 판단한 대가는 임무 전체다

④ 시뮬레이션 정책에게 현실은 늘 '처음 보는 환경'
실제 마찰·접촉·질량은 시뮬레이터 설정값과 다르다 (Sim-to-Real gap)
처음 보는 환경에서 걷는 능력 = 시뮬레이션에서 학습한 정책을 실제 로봇에 옮기기 위한 전제 조건

Ant(몸통 + 다리 4개, 관절 8개) = 4족 보행 로봇의 단순화 모델. 이 과제는 '학습한 바닥 밖에서도 걷는 능력'의 원리를 검증한다.

> **발표 멘트:** 다리 로봇은 바퀴가 못 가는 곳을 가기 위해 존재합니다. 그런데 그런 곳의 바닥은 미리 알 수 없고, 한 번 이동하는 동안에도 계속 바뀝니다. 넘어지면 임무가 끝나고, 시뮬레이션에서 학습한 정책에게는 현실 자체가 처음 보는 환경입니다. 그래서 이 과제의 '처음 보는 환경에서 걷기'는 보행 로봇을 실제로 쓸 수 있느냐의 문제입니다.

## 슬라이드 4

Problem Formulation & Research Hypothesis

Baseline의 한계: 지형 '모양'이 같아도, 바닥의 '느낌'이 바뀌면 무너진다

평면 바닥: 수학적으로 완벽히 매끈한 무한 평면 → 발이 닿는 방식이 항상 일정
메쉬 바닥: 실제 지형처럼 작은 삼각형 면을 이어 붙인 바닥 → 모양은 평지여도 반발·미끄러짐이 다르다

Baseline이 학습한 세계
무한히 넓은 완벽한 평면 하나
마찰 1.0 고정 · 질량 고정 · 외부 충격 없음

−68%
같은 평지, 메쉬 바닥
129.6 → 41.7

−72%
처음 보는 지형·물성
129.6 → 36.3

반대로, 평면에서 마찰만 바꾸면?
마찰 0.3 / 0.5 / 0.7 / 1.0 → 120 / 126 / 131 / 130
→ 원인은 마찰 숫자가 아니라 바닥과 접촉하는 방식

## 슬라이드 5

Problem Formulation & Research Hypothesis

문제 정의: Ant는 지금 밟고 있는 바닥이 어떤 바닥인지 모른다

연구 질문  처음 보는 환경에서 Ant의 보행 성능은 왜 떨어지는가?

P1. 한 가지 바닥만 경험했다
학습 분포 과적합
평생 한 종류의 바닥에서만 학습
→ 그 바닥에서 가장 빠른 질주 보법(평균 8.6 m/s) 하나만 안다
바닥이 바뀌어도 같은 보법으로 달린다 → 미끄러지거나 발이 걸려 넘어짐
처음 보는 환경 평균 전진 속도 2.6 m/s

P2. 바닥을 느낄 수 없다
바닥 물성의 관측 불가능성
받는 정보 60개: 몸통 높이·속도·기울기, 목표 방향, 관절 각도·속도, 발목 관절에 걸리는 힘, 직전 행동
없는 것 ① 발이 지면을 얼마나, 어느 방향으로 미는지 / 미끄러지는지
없는 것 ② 과거 기록 (1/60초 한 순간만 봄)
→ 빙판인지 아스팔트인지 구분할 근거가 없어 보법을 바꿀 수 없다

P3. 앞을 볼 수 없다
지형 인식 부재
지형 높이를 재는 센서가 없다 → 턱·요철을 밟고 나서야 안다
몸통 높이도 절대 높이 → 솟은 지형 위에서는 '높이 떠 있다'고 착각

> **발표 멘트:** 연구 질문은 '처음 보는 환경에서 Ant는 왜 넘어지는가'입니다. 원인을 세 가지로 정리했습니다. 한 가지 바닥만 경험했고, 바닥을 느낄 감각이 없고, 앞을 볼 수 없습니다. 이 중 핵심은 두 번째, 바닥을 느낄 수 없다는 점입니다.

## 슬라이드 6

Problem Formulation & Research Hypothesis

연구 가설: '발바닥 감각'을 주면 처음 보는 바닥에서도 걸을 수 있다

|  | 가설 | 어떻게 검증하는가 | 해결 대상 |
|---|---|---|---|
| H1 / 원인 | 바닥이 어떤 바닥인지 알면, 정책 하나로 평지 질주와 험지 보행을 모두 잘할 수 있다 | 정답 바닥 정보(마찰·질량·평면 여부)를 직접 받는 교사 정책이 두 환경 모두에서 Baseline보다 높은가 | P1, P2 |
| H2 / 추정 | 바닥 정보는 발바닥 감각과 최근 움직임에 드러나므로, 정답 없이도 추정할 수 있다 | 정답 없이 발 접촉 센서 + 최근 0.13초 기록만 가진 학생 정책이 교사 성능을 회복하는가 | P2 |
| H3 / 일반화 | 실제 감각으로 판단하므로 학습에서 보지 못한 바닥에서도 통한다 | 학습에 쓰지 않은 지형·물성, 마찰 0.1~2.0에서 학생과 Baseline을 비교 | P3 (+P1) |

비유  사람은 빙판을 밟는 순간 미끄러움을 느끼고 보폭을 줄인다. Baseline Ant에게 없는 것이 바로 이 '발바닥 감각'이다.

> **발표 멘트:** 사람은 빙판을 밟는 순간 미끄러움을 느끼고 보폭을 줄입니다. Baseline Ant에게 없는 것이 바로 이 감각입니다. 그래서 세 가지 가설을 세웠습니다. H1은 원인 가설, H2는 추정 가설, H3는 일반화 가설입니다. 각 가설은 뒤에서 별도의 비교로 검증합니다.

Experimental Design

## 슬라이드 10

Experimental Design

가설 검증을 위한 설계: 가설마다 비교 대상을 하나씩 정했다

| 가설 | 비교 | 판단 기준 |
|---|---|---|
| H1 원인 | 교사 vs Baseline (기존 / 처음 보는 환경) | 바닥 정보가 있으면 두 환경 모두 Baseline보다 높은가 |
| H2 추정 | 학생 vs 교사 | 정답 없이 교사 성능에 얼마나 근접하는가 |
| H3 일반화 | 학생 vs Baseline (처음 보는 환경 · 지형별 · 마찰 0.1~2.0) | 학습 밖 모든 조건에서 Baseline보다 높은가 |
| 상한 | 오라클: 처음 보는 환경에서 직접 학습 (제출 X) | 이 시뮬레이터에서 도달 가능한 최대 점수 (67.2) |

로봇마다 마찰 하나
원래 방식은 부품마다 마찰을 따로 뽑아 로봇 전체 평균이 거의 같아진다 → 추정할 '바닥 차이'가 사라짐. 로봇 하나 = 바닥 하나로 변경

'웅크리기 꼼수' 차단
원래 넘어짐 판정(몸통 절대 높이 < 0.31 m)은 솟은 지형 위에서 몸을 낮게 깔아도 통과 → 학습 중에만 지형 기준 높이로 판정. 평가는 원래 판정

오라클로 상한 측정
처음 보는 환경에서 직접 학습한 정책도 67.2 → 정책의 한계와 시뮬레이터 접촉 모델의 한계를 분리

학습 반복 (seed)
교사-학생 전체 과정을 서로 다른 seed로 2회 반복해 결과가 재현되는지 확인

> **발표 멘트:** 가설마다 무엇과 무엇을 비교할지 미리 정했습니다. 오라클은 처음 보는 환경에서 직접 학습한 정책으로, 제출용이 아니라 도달 가능한 상한을 재기 위한 기준입니다. 아래 네 가지는 비교를 공정하게 만들기 위한 장치입니다.

교사: 기존 환경 145.5 (Baseline +15.9, p = 0.0001), 처음 보는 환경 56.7 (+20.5). 평지에서는 더 빨리(9.8 vs 8.6 m/s), 험지에서도 버틴다

R2 → H2 지지   발바닥 감각만으로 바닥을 추정한다
학생: 정답 바닥 정보 없이 기존 환경 138.4 = 교사의 95%. 발 접촉 + 0.13초 기록만으로 지금 밟는 바닥을 구분

R3 → H3 지지   처음 보는 환경으로 일반화된다
학생: 처음 보는 환경 64.6 = Baseline +78%. 교사보다도 +7.9 높다 (p = 0.048)

> **발표 멘트:** 결과를 가설별로 보겠습니다. 교사는 바닥을 알기 때문에 평지에서 Baseline보다 빨리 달리고 험지에서도 버팁니다. 평지와 험지 사이의 trade-off가 사라집니다. 학생은 정답 없이 교사 평지 성능의 95%를 되찾았고, 처음 보는 환경에서는 오히려 교사보다 높습니다.
